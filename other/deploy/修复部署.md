# 部署卡住 / 报错修复

## 原因

1. `ubuntu` 用户没有 Docker 权限 → MySQL 建库失败  
2. 后端连不上数据库 → 8083 一直起不来 → 脚本卡在「等待后端启动」

---

## 立即修复（在 OrcaTerm 终端执行）

### 1. 先按 `Ctrl + C` 停掉当前卡住的脚本

### 2. 复制下面整段执行

```bash
cd ~/big-screen-deploy

# 用 sudo 找 MySQL 容器并建库（密码默认 root，不对见下方说明）
MYSQL_CONTAINER=$(sudo docker ps --format '{{.Names}}' | grep -iE 'mysql|mariadb' | head -1)
echo "MySQL容器: $MYSQL_CONTAINER"
sudo docker exec -i "$MYSQL_CONTAINER" mysql -uroot -proot < init-mysql.sql

# 重启后端
cd /opt/big-screen-service
pkill -f goview_admin || true
sleep 2
nohup java -jar goview_admin-0.0.1-SNAPSHOT.war --spring.profiles.active=prod > app.log 2>&1 &
sleep 15
tail -40 app.log
sudo ss -tlnp | grep 8083

# 配置 Nginx（若第 4 步没跑过）
sudo cp -f ~/big-screen-deploy/nginx-big-screen.conf /etc/nginx/sites-available/big-screen
sudo ln -sf /etc/nginx/sites-available/big-screen /etc/nginx/sites-enabled/big-screen
sudo nginx -t && sudo systemctl reload nginx
sudo ss -tlnp | grep 8090
```

### 3. 浏览器访问

http://82.156.253.71:8090  
账号 `admin` / 密码 `123456`

---

## 若 MySQL 报 Access denied

说明 root 密码不是 `root`，先查其他项目用的密码：

```bash
grep -r password /opt/project-infra/ 2>/dev/null | head -5
grep -r MYSQL /opt/*/docker-compose*.yml 2>/dev/null | head -10
```

查到密码后：

```bash
export MYSQL_PWD=真实密码
sudo docker exec -i "$MYSQL_CONTAINER" mysql -uroot -p"$MYSQL_PWD" < ~/big-screen-deploy/init-mysql.sql
```

然后重新启动 Java（见上面 nohup 那几行）。
