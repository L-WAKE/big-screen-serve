# 域名访问配置（screen.liulaoban.online）

与现有项目对齐：

| 项目 | 域名 |
|------|------|
| 房源管理 | liulaoban.online |
| AI 知识库 | kb.liulaoban.online |
| **GoView 大屏** | **screen.liulaoban.online** |

---

## 第 1 步：DNS 解析（域名控制台）

登录 **liulaoban.online** 的域名服务商（腾讯云 DNS / 阿里云等），添加记录：

| 类型 | 主机记录 | 记录值 |
|------|----------|--------|
| A | screen | 82.156.253.71 |

保存后等待 5～10 分钟。

验证（Mac 或服务器）：

```bash
ping screen.liulaoban.online
```

能 ping 到 `82.156.253.71` 即可进行下一步。

---

## 第 2 步：服务器配置 Nginx（OrcaTerm 执行）

```bash
sudo tee /etc/nginx/sites-available/big-screen > /dev/null <<'NGINX'
server {
    listen 80;
    server_name screen.liulaoban.online;

    root /var/www/big-screen/dist;
    index index.html;
    client_max_body_size 50m;

    location /api/ {
        proxy_pass http://127.0.0.1:8083;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /oss/ {
        proxy_pass http://127.0.0.1:8083;
        proxy_set_header Host $host;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}

server {
    listen 8090;
    server_name 82.156.253.71;

    root /var/www/big-screen/dist;
    index index.html;
    client_max_body_size 50m;

    location /api/ {
        proxy_pass http://127.0.0.1:8083;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /oss/ {
        proxy_pass http://127.0.0.1:8083;
        proxy_set_header Host $host;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
NGINX

sudo ln -sf /etc/nginx/sites-available/big-screen /etc/nginx/sites-enabled/big-screen
sudo nginx -t && sudo systemctl reload nginx
```

先测 HTTP：http://screen.liulaoban.online（应能看到登录页）

---

## 第 3 步：申请 HTTPS 证书（与 kb 一样）

```bash
sudo certbot --nginx -d screen.liulaoban.online
```

按提示：输入邮箱 → 同意协议 → 选是否跳转 HTTPS（建议选 **2 重定向**，自动 http→https）

完成后访问：**https://screen.liulaoban.online**

---

## 第 4 步：更新后端图片地址（服务器执行）

```bash
sudo tee /opt/big-screen-service/application-override.yml > /dev/null <<'EOF'
spring:
  datasource:
    password: 这里保持原来的密码，不要删这行！先 cat 看旧文件
EOF
```

**不要覆盖密码！** 只追加 v2 配置，执行：

```bash
# 先看现有 override 里密码还在不在
cat /opt/big-screen-service/application-override.yml

# 若没有 v2 段，手动编辑加上（密码行保留）：
sudo nano /opt/big-screen-service/application-override.yml
```

在文件里加上（密码那行保留不动）：

```yaml
v2:
  httpurl: https://screen.liulaoban.online/
```

然后重启后端：

```bash
cd /opt/big-screen-service
pkill -f goview_admin || true
sleep 2
nohup java -jar goview_admin-0.0.1-SNAPSHOT.war \
  --spring.profiles.active=prod \
  --spring.config.additional-location=file:/opt/big-screen-service/application-override.yml \
  > app.log 2>&1 &
```

---

## 第 5 步：重新打包前端（Mac 本地，HTTPS 后执行）

`.env.production` 已是 `https://screen.liulaoban.online`，本地执行：

```bash
cd go-view && pnpm build
scp -r dist/* ubuntu@82.156.253.71:/var/www/big-screen/dist/
```

（若 scp 不可用，用 OrcaTerm 上传 dist 覆盖）
