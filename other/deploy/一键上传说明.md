# 你只需要做 2 件事（约 3 分钟）

本地已全部打好包，文件在：

```
deploy/big-screen-deploy.tar.gz   （约 60MB）
```

---

## 操作 1：上传压缩包到服务器

1. 打开 OrcaTerm，左侧**文件管理器**进入 `/home/ubuntu`
2. 点击**上传**，选择本机文件：
   `goview/deploy/big-screen-deploy.tar.gz`
3. 等上传完成

---

## 操作 2：解压并一键部署

右侧**终端**复制执行：

```bash
cd ~
mkdir -p big-screen-deploy
tar -xzf big-screen-deploy.tar.gz -C big-screen-deploy
cd big-screen-deploy
bash server-setup.sh
```

看到 `部署完成` 后，浏览器打开：**http://82.156.253.71:8090**

- 账号：`admin`
- 密码：`123456`

---

## 若 MySQL 报错（密码不是 root）

```bash
export MYSQL_PWD=你的MySQL真实密码
cd ~/big-screen-deploy && bash server-setup.sh
```

查看后端日志：

```bash
tail -50 /opt/big-screen-service/app.log
```

---

## 腾讯云安全组

若 8090 打不开，控制台 → 安全组 → 入站规则 → 放行 **8090**（与 8088、8089 相同）。
