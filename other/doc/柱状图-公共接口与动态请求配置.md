# 柱状图：公共接口与动态请求配置说明

本文档以 **柱状图（BarCommon）** 为例，说明 GoView 中「公共接口」与「动态请求」的完整配置参数、操作步骤及接口返回值。

---

## 前置条件

### 1. 启动项目

```bash
# 推荐（持久启动）
./scripts/dev-start.sh

# 查看状态
./scripts/dev-status.sh
```

| 服务 | 地址 |
|------|------|
| 前端 | http://localhost:3020 |
| 后端 | http://localhost:8083 |
| 登录账号 | admin / 123456 |

### 2. 柱状图数据映射字段

柱状图组件默认 dataset 结构如下：

| 映射项 | 字段名 | 说明 |
|--------|--------|------|
| 通用标识（X 轴） | `product` | 类目，如 Mon、Tue |
| 数据项-1 | `data1` | 第一组柱形数据 |
| 数据项-2 | `data2` | 第二组柱形数据 |

图表所需最终格式：

```json
{
  "dimensions": ["product", "data1", "data2"],
  "source": [
    { "product": "Mon", "data1": 120, "data2": 130 }
  ]
}
```

### 3. 公共鉴权参数

两个接口均需在请求头携带 token：

| 参数位置 | Key | Value |
|----------|-----|-------|
| Header | `token` | `goview-bar-demo-token` |

可在后端 `go-view-serve/src/main/resources/application.yml` 中修改：

```yaml
goview:
  chart-demo-token: goview-bar-demo-token
```

## 一、公共接口配置

> **特点**：接口配置保存在「全局数据池」，可被多个组件复用。

### 1.1 接口信息

| 配置项 | 值 |
|--------|-----|
| 完整地址 | `http://localhost:8083/api/chart/bar-common` |
| 请求方式 | `GET` |
| 鉴权 Header | `token: goview-bar-demo-token` |
| 后端 Controller | `ChartDataApiController#barCommon` |

**接口返回示例：**

```json
{
  "code": 0,
  "msg": "操作成功",
  "data": {
    "list": [
      { "product": "Mon", "data1": 120, "data2": 130 },
      { "product": "Tue", "data1": 200, "data2": 130 },
      { "product": "Wed", "data1": 150, "data2": 312 },
      { "product": "Thu", "data1": 80, "data2": 268 },
      { "product": "Fri", "data1": 70, "data2": 155 },
      { "product": "Sat", "data1": 110, "data2": 117 },
      { "product": "Sun", "data1": 130, "data2": 160 }
    ],
    "crossrangeList": [
      { "product": "华东", "data1": 320, "data2": 280 },
      { "product": "华南", "data1": 250, "data2": 210 },
      { "product": "华北", "data1": 180, "data2": 160 },
      { "product": "西南", "data1": 140, "data2": 120 },
      { "product": "西北", "data1": 110, "data2": 95 },
      { "product": "东北", "data1": 85, "data2": 70 },
      { "product": "华中", "data1": 200, "data2": 175 }
    ]
  }
}
```

| 数据字段 | 用途 |
|----------|------|
| `data.list` | 纵向柱状图 |
| `data.crossrangeList` | 横向柱状图 |

**curl 测试：**

```bash
curl -H "token: goview-bar-demo-token" http://localhost:8083/api/chart/bar-common
```

### 1.2 操作步骤

#### 步骤 1：选中柱状图

1. 打开 GoView 编辑器（http://localhost:3020）
2. 在画布中点击 **柱状图** 组件
3. 右侧切换到 **「数据」** 面板

#### 步骤 2：切换请求方式

| 配置项 | 值 |
|--------|-----|
| 请求方式 | **公共接口** |

#### 步骤 3：创建并配置公共接口

1. 点击 **「编辑配置」**
2. 左侧点击 **「+」** 新建公共接口
3. 在弹窗中按下方参数填写

**全局公共配置：**

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 前置 URL | `http://localhost:8083` | 全局服务地址 |
| 更新间隔 | `0` | 0 表示仅初始化时请求一次 |
| 更新间隔单位 | `秒` | 默认即可 |

**公共接口详情：**

| 配置项 | 值 |
|--------|-----|
| 名称 | `柱状图公共接口` |
| 请求方式 | `GET` |
| URL 地址 | `/api/chart/bar-common` |
| 请求内容类型 | `普通请求` |
| 请求体类型 | `none` |
| 选择方式 | **Header** |

**Header 参数：**

| Key | Value |
|-----|-------|
| `token` | `goview-bar-demo-token` |

4. 点击 **「保存」**
5. 在左侧列表 **选中** 刚创建的公共接口
6. 点击 **「保存 & 发送请求」**

#### 步骤 4：配置数据过滤器

在 **数据过滤** 区域点击 **「新增过滤器」**，填入：

```javascript
return {
  dimensions: ['product', 'data1', 'data2'],
  source: data?.list || []
}
```

| 说明 | 内容 |
|------|------|
| 过滤器入参 `data` | 接口返回的 `data` 字段（含 `list` 数组） |
| 过滤器入参 `res` | 接口完整响应 `{ code, msg, data }` |
| 转换目标 | ECharts dataset 格式 |

点击 **「保存」**。

#### 步骤 5：验证

1. 点击 **「发送请求」**
2. 确认 **数据映射** 显示：

| 映射项 | 字段 | 状态 |
|--------|------|------|
| 通用标识 | `product` | 匹配成功 |
| 数据项-1 | `data1` | 匹配成功 |
| 数据项-2 | `data2` | 匹配成功 |

3. 柱状图应显示 Mon～Sun 共 7 天数据（data1 约 120、200、150…）

### 1.3 配置参数汇总

| 分类 | 参数 | 值 |
|------|------|-----|
| 全局 | 前置 URL | `http://localhost:8083` |
| 全局 | 更新间隔 | `0` |
| 接口 | 名称 | `柱状图公共接口` |
| 接口 | 请求方式 | `GET` |
| 接口 | URL | `/api/chart/bar-common` |
| 接口 | Header.token | `goview-bar-demo-token` |
| 过滤器 | dimensions | `['product', 'data1', 'data2']` |
| 过滤器 | source | `data.list` |

### 1.4 横向柱状图复用同一公共接口

> 与纵向柱状图共用 `柱状图公共接口`，仅 **数据过滤器** 不同。

#### 操作步骤

1. 选中画布中的 **横向柱状图**
2. 右侧 **「数据」** → 请求方式选 **公共接口**
3. **编辑配置** → 选中已有的 `柱状图公共接口` → **保存 & 发送请求**
4. **数据过滤** 新增过滤器，填入：

```javascript
return {
  dimensions: ['product', 'data1', 'data2'],
  source: data?.crossrangeList || []
}
```

5. 点击 **「发送请求」**，确认数据映射三项 **匹配成功**
6. 图表应显示 **华东、华南、华北…** 区域数据（data1 首值约 320）

| 分类 | 参数 | 值 |
|------|------|-----|
| 接口 | URL | `/api/chart/bar-common`（与纵向柱状图相同） |
| 过滤器 | source | `data.crossrangeList` |

## 二、动态请求配置

> **特点**：请求配置绑定在当前组件上，每个图表可独立配置不同接口。

### 2.1 接口信息

| 配置项 | 值 |
|--------|-----|
| 完整地址 | `http://localhost:8083/api/chart/bar-ajax` |
| 请求方式 | `GET` |
| 鉴权 Header | `token: goview-bar-demo-token` |
| 后端 Controller | `ChartDataApiController#barAjax` |

**接口返回示例：**

```json
{
  "code": 0,
  "msg": "操作成功",
  "data": {
    "result": {
      "updateTime": 1716192000000,
      "rows": [
        { "product": "Mon", "data1": 180, "data2": 90 },
        { "product": "Tue", "data1": 260, "data2": 150 },
        { "product": "Wed", "data1": 190, "data2": 280 },
        { "product": "Thu", "data1": 120, "data2": 220 },
        { "product": "Fri", "data1": 95, "data2": 175 },
        { "product": "Sat", "data1": 140, "data2": 130 },
        { "product": "Sun", "data1": 210, "data2": 190 }
      ]
    }
  }
}
```

**curl 测试：**

```bash
curl -H "token: goview-bar-demo-token" http://localhost:8083/api/chart/bar-ajax
```

### 2.2 操作步骤

#### 步骤 1：选中柱状图

1. 打开 GoView 编辑器
2. 点击画布中的 **柱状图** 组件
3. 右侧切换到 **「数据」** 面板

#### 步骤 2：切换请求方式

| 配置项 | 值 |
|--------|-----|
| 请求方式 | **动态请求** |

#### 步骤 3：编辑请求配置

1. 点击 **「编辑配置」**
2. 在弹窗中按下方参数填写

**全局公共配置：**

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 前置 URL | `http://localhost:8083` | 全局服务地址 |
| 更新间隔 | `0` | 0 表示仅初始化时请求一次 |
| 更新间隔单位 | `秒` | 默认即可 |

**组件请求配置：**

| 配置项 | 值 |
|--------|-----|
| 请求方式 | `GET` |
| URL 地址 | `/api/chart/bar-ajax` |
| 请求内容类型 | `普通请求` |
| 请求体类型 | `none` |
| 组件更新间隔 | 留空（使用全局间隔） |
| 选择方式 | **Header** |

**Header 参数：**

| Key | Value |
|-----|-------|
| `token` | `goview-bar-demo-token` |

3. 点击 **「保存 & 发送请求」**

#### 步骤 4：配置数据过滤器

在 **数据过滤** 区域点击 **「新增过滤器」**，填入：

```javascript
return {
  dimensions: ['product', 'data1', 'data2'],
  source: data?.result?.rows || []
}
```

| 说明 | 内容 |
|------|------|
| 过滤器入参 `data` | 接口返回的 `data` 字段（含 `result.rows`） |
| 过滤器入参 `res` | 接口完整响应 `{ code, msg, data }` |
| 转换目标 | ECharts dataset 格式 |

点击 **「保存」**。

#### 步骤 5：验证

1. 点击 **「发送请求」**
2. 确认 **数据映射** 三项均为 **匹配成功**
3. 柱状图应显示 Mon～Sun 数据（data1 约 180、260、190…，与公共接口数值不同）

### 2.3 配置参数汇总

| 分类 | 参数 | 值 |
|------|------|-----|
| 全局 | 前置 URL | `http://localhost:8083` |
| 全局 | 更新间隔 | `0` |
| 组件 | 请求方式 | `GET` |
| 组件 | URL | `/api/chart/bar-ajax` |
| 组件 | Header.token | `goview-bar-demo-token` |
| 过滤器 | dimensions | `['product', 'data1', 'data2']` |
| 过滤器 | source | `data.result.rows` |

## 三、两种方式对比

| 对比项 | 公共接口 | 动态请求 |
|--------|----------|----------|
| 请求方式选项 | 公共接口 | 动态请求 |
| 配置存储位置 | 全局数据池 | 当前组件 |
| 多组件复用 | 支持 | 不支持（各配各的） |
| 编辑入口 | 编辑配置 → 新建/选择数据池 | 编辑配置 → 组件请求 |
| 接口地址 | `/api/chart/bar-common` | `/api/chart/bar-ajax` |
| 数据路径 | `data.list` | `data.result.rows` |
| 示例 data1 首值 | 120 | 180 |
| 编辑态自动请求 | 需手动发送请求 | 配置后自动请求 |
| 预览态轮询 | 支持 | 支持 |

## 四、常见问题

| 现象 | 原因 | 处理方式 |
|------|------|----------|
| 过滤器报错 `Cannot read properties of undefined` | 接口未返回数据 | 先确认后端已启动，再点「发送请求」 |
| 没有拿到返回值 | URL 或 token 配置错误 | 检查前置 URL、接口路径、Header token |
| 数据映射匹配失败 | 未配置过滤器或字段名不对 | 按文档配置过滤器，确保含 product/data1/data2 |
| 401 / token 无效 | Header 未配置或 token 错误 | Header 添加 `token: goview-bar-demo-token` |
| ECharts setOption 警告 | 数据更新时图表重绘时序问题 | 一般可忽略，不影响数据显示 |
| 修改接口代码后不生效 | 后端未重启 | 执行 `./scripts/dev-start.sh` 重启后端 |
